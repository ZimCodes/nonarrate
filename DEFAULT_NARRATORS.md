# Default Narrators

This is a list of common narrator/introspection phrases that are removed by default. *(includes capital case too)*

- thought
- thoughts
- thinking
- mind
- narrator
- inner voice
- inner monologue

## Built-In Narrators

Narrator character objects available to developers by default. [Ren'Py's Reserved Names](https://www.renpy.org/doc/html/reserved.html)

- `nvl_narrator`
- `narrator`

## Common Descriptors

Common descriptor words and phrases in a parenthetical. *(Includes capital case)*

- thinking
- think
- thoughts
- thought
- inner voice
- inner voices
- inner monologue
